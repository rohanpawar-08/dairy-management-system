# Dairy Management System

**महाराष्ट्रातील दूध संकलन केंद्रांसाठी सोपी, offline-first Windows desktop प्रणाली.**

Dairy Management System हे दूध संकलन केंद्र आणि डेअरी व्यवसायातील रोजचे काम व्यवस्थित नोंदवण्यासाठी तयार केलेले software आहे. इंटरनेट उपलब्ध नसतानाही स्थानिक संगणकावर काम करता यावे आणि दूध संकलनापासून शेतकऱ्यांच्या हिशोबापर्यंतची माहिती एकाच ठिकाणी व्यवस्थापित करता यावी, हा या उत्पादनाचा मुख्य उद्देश आहे.

## मुख्य सुविधा

- **शेतकरी व्यवस्थापन** — शेतकरी नोंदणी आणि माहिती व्यवस्थापन
- **दूध संकलन** — गाय व म्हैस दूध, सकाळ/संध्याकाळ शिफ्ट आणि संकलन नोंदी
- **FAT/SNF दर गणना** — मंजूर दरपत्रकानुसार दूध रकमेची गणना
- **शेतकरी खातेवही** — जमा, कपात, अॅडव्हान्स आणि बाकी रकमेचा हिशोब
- **आठवड्याचा हिशोब व पेमेंट** — सेटलमेंट आणि पेमेंट नोंदी
- **अहवाल व प्रिंटिंग** — संकलन, खातेवही आणि सेटलमेंट अहवाल
- **बॅकअप व पुनर्संचयित** — स्थानिक डेटाचा बॅकअप आणि आवश्यकतेनुसार restore
- **Marathi आणि English** — दोन्ही भाषांमध्ये वापरासाठी समर्थन

## उत्पादनाची माहिती

- **प्लॅटफॉर्म:** Windows desktop
- **काम करण्याची पद्धत:** Offline-first; डेटा स्थानिक संगणकावर साठवला जातो
- **मुख्य तंत्रज्ञान:** Angular, TypeScript, Electron आणि SQLite

Dairy Management System चे उद्दिष्ट म्हणजे दूध संकलन केंद्रातील दैनंदिन नोंदी, गणना आणि शेतकऱ्यांचे हिशोब अधिक सोपे, स्पष्ट आणि व्यवस्थित बनवणे.
